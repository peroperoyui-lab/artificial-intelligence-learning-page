## 260 参数解码器的确切结构

`src/engine-microgpt.js` 实现原生 JavaScript 标量反向自动微分和一个单头、单块、宽度 4 的因果 Transformer。训练代码与自动微分为本项目原创；没有复制第三方 micrograd/microGPT 实现。

```text
字符 ID → 词嵌入 + 可学习绝对位置
       → x + Attention(RMSNorm(x))
       → h + Linear(ReLU(Linear(RMSNorm(h))))
       → RMSNorm → 独立词表投影 → logits
```

| 参数族 | 形状 | 个数 |
|---|---|---:|
| 词嵌入 | 11×4 | 44 |
| 位置表 | 8×4 | 32 |
| Q/K/V 与注意力输出投影 | 4 组 4×4 | 64 |
| 三组 RMSNorm 增益 | 3×4 | 12 |
| 前馈上/下投影 | 8×4 与 4×8 | 64 |
| 独立词表头 | 11×4 | 44 |
| **合计** | | **260** |

没有偏置、Dropout、权重衰减或嵌入权重共享。采用 Pre-RMSNorm，epsilon=10⁻⁵、激活为 ReLU；并未把独立专题里的 RoPE/SwiGLU/GQA 全部加入这个训练器。已注册参数都交给优化器，不代表每条样本或每个位置都会产生非零梯度；最高几个位置没有被这些短训练句覆盖。

词表：`BOS、EOS、红、蓝、小、猫、鸟、吃、鱼、米、。`。

训练句：`猫吃鱼。`、`鸟吃米。`、`红猫吃鱼。`、`蓝鸟吃米。`、`小猫吃鱼。`、`小鸟吃米。`。

验证句：`蓝猫吃鱼。`、`红鸟吃米。`。句子为原创人工数据；验证组合未参与梯度，样本量不足以论证通用语言能力。

**训练口径**：每步按固定顺序取一条句子，使用该句有效目标的平均 CE 求梯度；整句等频，因此优化过程是句子等权。显示训练/验证曲线时，分别按各自全语料的有效词元数加权平均。这两种平均口径明确区分。梯度全局范数裁剪为 1，Adam β₁=.9、β₂=.999、epsilon=10⁻⁸，无衰减；学习率 .001–.05，默认 .02。最多 600 步，每 12 步或手动更新后评估，快照保留 `metricsAtStep`，不把尚未刷新的损失当作当前步的重新评估。

**生成口径**：给定最多 7 个合法字符，前置 BOS；每一步重算不超过 8 个输入位置的完整因果前向，排除 BOS 后应用温度/top-p，采样一个 token 并接回上下文，遇 EOS 或预算停止。没有模板补句或预录输出。界面的分布条是当前前缀的原始概率，含 BOS；生成结果标明生成时的训练步数。改变参数后需要重新生成。

**模型文件**：独立格式 `visible-microgpt-v1`，存 seed、steps、260 维 p/m/v。采用明确尺寸、有限数值、非负二阶矩校验；≤100 KB，先构建候选再整体替换，异步导入检查页面销毁与版本。词表、结构、语料和固定样本顺序由此版本确定。学习率及采样设置不在文件中，恢复相同的下一步还须使用相同学习率；没有自动恢复整条历史曲线。原 MLP 的 `visible-ai-model-v1` 不受影响，两个格式不能混用。

## 其他数值约定

**BPE** 从 Unicode 码点开始，不跨空白，只合并频率至少 2 的对；统计相邻出现次数，执行从左到右非重叠替换。当前唯一片段集合不是完整部署词表。

**LoRA** 只拟合 `BA` 到固定秩二 4×4 目标，基座 W₀=0、α=r，缩放为 1。A 随机、B=0，MSE 对 16 项平均，SGD .5，最多 300 步。第一步 A 梯度为零，之后可以获得非零梯度。

**KV** 使用人工 Q/K/V，真实比较逐步缓存和完整因果输出；投影行数不是完整 FLOPs。资源计算按 16 位 KV、24 层、单请求、头维64，KV 头数与长度可调。

**预算** 稠密训练 FLOPs 近似 6ND；Adam 混合精度状态按 16 字节/参数假设，推理净权重按位宽计算，二者不随推理量化同时下降。不计激活、临时缓冲、量化元数据和通信；设备数只影响理想吞吐和有效批量，不模拟参数分片。

**采样** 温度→top-k→重归一化→top-p→重归一化；固定 logits 的计数实验与微型解码器自回归区别显示。

**量化** 对称均匀、每组 32bit scale，误差对原始未裁剪值计算。整数存在 JavaScript 数组中，没有压成低位二进制；位数账本不是浏览器实际内存。

**MoE** top-k 内先归一化，再按 token 顺序接受分支；溢出丢弃，不对剩余权重再次归一化。本例不计算专家网络输出。

**检索** 对字符及相邻二元片段做 TF-IDF 余弦相似度，最多20文档的引擎上限，站内六篇原创资料；零得分明确无匹配信号，不宣称语义召回。

**调度** 所有请求 t=0 到达，每 tick 每活跃请求输出一个 token，忽略 prefill、传输、到达过程和真实 GPU 批处理开销。静态批次的请求可先完成，但槽位待整批完成再复用；连续批次下一个 tick 补入。

## 性能和生命周期

保持普通脚本、CPU、零生产依赖，全文与资源打包为单文件。微型解码器每步创建临时计算图并释放，不把全历史图留在内存；20ms 计时器只作为调度间隔，不承诺20ms完成训练。运行时间取决于浏览器和设备。

上限：BPE 800 字符/24次合并；缓存等价性12位置；微型解码器8位置/600步；LoRA300步；量化16数值；MoE6token×4专家；检索六段资料；图像8×8；调度六请求。算法 API 也有输入边界检查。资源预算中的数十亿参数只参与算术，绝不分配同规模张量。

训练循环使用 `U.Loop`，离页 `dispose()`，隐藏暂停且不自行恢复。导入不执行代码，用户文本转义；没有账户、遥测、远程模型、预训练权重或字体下载。
