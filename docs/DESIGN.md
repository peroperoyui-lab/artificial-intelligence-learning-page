# 教学结构与工程设计

## 学习路线

本站面向具备基本数字直觉、希望理解机制而不只记住术语的中文学习者。13 章形成一条主线：任务定位 → 数字表示 → 预测函数 → 神经元 → 损失 → 梯度下降 → 反向传播 → 真实训练 → 泛化与评价 → 卷积 → 注意力 → 词元采样。

每章首先提供可验证的操作任务，再解释刚才发生的现象，最后用可展开公式补足技术细节。自测题允许反复选择，完成进度由学习者手动确认；系统不把“打开过页面”当成“已经掌握”。

这不是完整 AI 学科百科。强化学习仅在知识地图定位；未提供扩散模型、工业规模 Transformer 或大型语言模型训练。1.2补充了一个可完整训练的260参数因果解码器，明确区别于通用大语言模型。

## 真实计算与教学假设

所有变化都由输入参数重新计算。线性回归使用真实梯度，多项式页面使用实际最小二乘，卷积逐项乘加，网络训练场实现解析反向传播。注意力使用人工设定的 Q/K/V，词元实验从人工 logits 的固定分布抽样；这两处不声称有预训练语义或自回归生成能力。

MLP 训练用合成数据，按类别分层划分 180 条训练和 60 条验证；验证数据不参与梯度。没有最终测试集，反复调整配置的实验不能被解释为未受选择影响的最终模型评价。

## 视觉与交互

浅色工作台、墨色正文，青色与橙色承担有意义的对照。类别还以圆点 / 三角区分，验证样本为空心方形；曲线使用实线 / 虚线，避免只依赖颜色。动作由用户触发，没有自动播放的装饰动画。所有播放循环在页面隐藏或路由切换时停止，不自行恢复。

提供跳到正文、可见键盘焦点、原生表单标签、对话框搜索、手动专注模式和减少过渡动画。SVG 提供标题 / 文本描述，Canvas 邻接参数、指标和可键盘输入的探测器。屏幕阅读器和其他辅助技术仍需用户环境下进一步体验检验，不能仅凭属性存在宣称完全符合 WCAG。

## 工程划分

- `engine.js`：不依赖 DOM 的数学与模型实现，可直接由 Node.js 测试。
- `content.js`：章节、术语、前置关系与来源数据。
- `ui.js`：表单、图形、数值格式、本地状态与有生命周期的播放循环。
- `labs-core.js` / `labs-advanced.js`：章节交互的挂载函数。
- `playground.js`：训练场、严格的数据型模型导入协议。
- `app.js`：路由、目录、搜索、阅读页、笔记、自测和实验本。

普通 deferred scripts 保持 `file://` 下可打开，不需要 import 请求或服务端路由。构建过程将脚本按原顺序移到单文件页面正文末尾，使用回调替换保留 JavaScript 中的字面美元符号。

每个 `AI.labs[id](element)` 挂载交互，提供 `element.getSnapshot()`，存在播放循环时返回清理函数。路由器离开旧页前调用清理函数。新增章节需同步 `content.js`、实验挂载和测试；不要直接把计时器留在全局。

## 可复现与保存

数据、权重和批次随机序列使用有状态的种子随机数。模型 JSON 记录结构、配置、所有权重和偏置、Adam 一阶与二阶矩、优化器步数、完整轮次和批次随机状态；导入采用校验后再整体替换，失败不留下半个新模型。

本地学习记录保存于浏览器 `localStorage`。失败时显示提示，当前内存内容仍可导出。没有账户、云同步、遥测和后端。学习记录导出是备份，当前不支持导回；模型文件支持导入并继续训练。

## 后续扩展建议

优先增强可解释细节，例如点击隐藏神经元查看特征图、以小计算图走完一个两层网络的完整反传、对同一数据保存两组并排对照。添加真实语言或图像模型时应隔离到独立模块，说明下载量、运行需求、模型许可和隐私边界，保持当前基础课程可离线独立使用。

## 大语言模型进阶（1.2）

进阶路线提供独立总览 `#/llm`，按语言表示、训练适配、推理应用组织。每章保留实验—解释—公式—迁移练习—自测/笔记路径；新增微型解码器、LoRA矩阵训练与轻量数值案例，不改变基础课的入口与存储。

深度学习语言模型并不限于D2L原书的一个Transformer版本。课程以D2L数学和序列建模为主线，现代部件和后训练另引原论文与官方文档。对未实现的工业训练、内核或模型能力明确说明，具体接口与预算见 [LLM_TRACK.md](LLM_TRACK.md)。
